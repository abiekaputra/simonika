# Security policy

## Reporting

Please report a suspected vulnerability privately to the repository owner through the contact address on the GitHub profile. Do not include credentials or personal data in a public issue.

## Supported version

Security fixes target the latest revision of the `main` branch.

## Data handling

This public repository is a portfolio edition. It must contain only synthetic data. Production exports, employee records, application keys, database snapshots, internal hostnames, and mail credentials must remain outside version control.
